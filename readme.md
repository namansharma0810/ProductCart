# 🛒 Product Cart

A responsive **Product Cart** web application built using HTML, CSS, and JavaScript.  
The project allows users to browse products, search for products, filter them, and sort products based on price and rating.

## 🚀 Features

- 🔍 Search products
- 📦 Display products dynamically
- 🏷️ Select products by category
- 💰 Sort by price
  - High to Low
  - Low to High
- ⭐ Sort by rating
  - High to Low
  - Low to High
- 🖼️ Dynamic product images
- 📱 Responsive design
- ⌨️ Search products using the Enter key
- 🔄 Fetch products from an API

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- DummyJSON API
